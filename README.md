A two-part micro-confession — a `To:` line naming who it was meant for, and the unsent line itself, exactly as it was typed — written to `/output/entry.txt` for make.fun's "Unsent: The Micro-Confession Sprint" bounty.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The entry is 124 characters in total: a `To: Dad` line and one 116-character unsent line about rehearsing a confession that never left the drafts.
